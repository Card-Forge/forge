Forge 简体中文民间汉化版
版本：2.0.15-汉化-08.13.1
发布日期：2026年8月13日

重要说明

本版本由社区爱好者制作，是基于开源项目 Forge 的非官方简体中文版本，与 Card Forge 官方及 Wizards of the Coast 无隶属或授权关系。

本软件以及本项目提供的安装包、更新服务和卡图下载服务完全免费。请勿向任何人付费购买本群发布的安装包。

交流与问题反馈：QQ群 813597628
汉化版开源分支：https://github.com/kaorou-bot/forge/tree/zh-cn-community-release
Forge 上游项目：https://github.com/Card-Forge/forge

主要更新

1. 简体中文界面
- 补充并修正桌面端、安卓端的简体中文界面文本，新安装默认使用简体中文。
- 修正部分未翻译、翻译不准确、占位符错误和中英文混排文本。
- forge.profile.properties.example 用户目录配置示例已汉化。

2. 中文卡牌资料
- 内置简体中文卡名映射，并补充卡名、类别和规则叙述的中文显示支持。
- 更新至 2026 年 8 月 13 日卡名映射，新增 892 个英文键并更新 185 条已有记录。
- 修正规则叙述含竖线表格时被截断的问题，掷骰、太空船和行星等牌张可完整显示中文规则。
- 兼容双面牌、不同版本牌图和特殊画框文件名。
- 卡图缺失时从民间汉化版卡图服务器按需下载。

3. 中文字体与输入
- 安卓安装包内置 CJK 中文字体，首次启动无需另行下载字体。
- 修复安卓端中文输入法支持，包括拼音组合、候选词选择和中文文本提交。

4. 民间汉化版更新与卡图渠道
- 自动更新仅使用本民间汉化版维护者配置的更新服务器。
- 桌面版、安卓 APK 和安卓资源包通过民间汉化版更新服务器发布。
- 桌面端和安卓端的卡图请求已切换至民间汉化版卡图服务器，支持缺失卡图按需下载。
- 桌面端与安卓端均移除了“下载全部卡图”功能。

5. Windows 免 Java 运行
- Windows 完整版内置 Java 21 运行环境，无需另外安装 JRE 或 JDK。
- 启动器优先使用安装包内的 Java，减少系统 Java 版本不兼容问题。

6. 安卓稳定性修复
- 修复部分设备首次启动时 CJK 字体尚未解包而导致的界面异常或崩溃。
- 修复授权存储权限并确认运行后进入黑屏的问题。
- 将 libGDX 启动所需的默认字体资源直接内置进 APK。

7. 08.13 社区版修复
- 原版面向用户的 Discord、论坛和错误反馈入口统一替换为 QQ 群 813597628。
- 停用向原版 Sentry 服务自动发送错误报告的功能；错误详情保留在本地，可自行发到群内反馈。
- 修复安卓发布说明中“桌面端、默认、占位符”等文字显示为方框的问题。
- 强制重建新版中文字体缓存，发布说明和联系方式所需汉字均已收录。

安装与升级提示

- Windows：下载 ZIP 后完整解压到新目录，再双击 forge.exe；不要直接在压缩包内运行。
- Android：下载 APK 后直接安装；签名一致时可覆盖安装并保留数据。
- 首次安装 Android 版后，程序可能继续下载约 181 MiB 的资源包，建议使用稳定的 Wi-Fi。
- 卡图采用按需下载，第一次查看尚未缓存的卡牌时需要保持网络连接。
- 升级前建议备份重要牌组、存档和设置。
