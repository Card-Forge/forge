FORGE WORKSHOP · 0.1.0 BETA

A desktop deck builder using Forge’s real card library and deck rules. Search, import, edit, save, and try opening hands.

Format checks cover deck structure. Rotating set legality and ban lists are not checked. The practice table does not run matches or AI opponents.

Your decks save locally after each edit. Card illustrations load from Scryfall when available and are cached for offline use. Illustrations may show a different printing from the deck entry.
