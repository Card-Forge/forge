# R10: the remaining optional-cost shapes and triggered `AB$` `Cost$`

Open-plan row R10. A triggered `AB$` line's `Cost$` is paid as the ability resolves (`WrappedAbility.java:440`,
`PlaySpellAbility.playSpellAbilityNoStack` `:574-579`), through `Registry.payTriggeredCost` (`effect.go`). Its refusals
(72 cards at the start of the row) were cost shapes `parseUnlessCost` did not read; five `Mode$ OptionalCost` cards were
refused or silently half-played for shapes of their own.

## Triggered `AB$` `Cost$` with X

| Piece | Port |
| --- | --- |
| Announced X | A cost naming X (a mana `X` or a part of amount X, `Cost.hasXInAnyCostPart`) whose SVar X is `Count$xPaid` or absent is announced once the controller agrees to pay (`PlaySpellAbility.announceValuesLikeX`, `:766-782`, which runs for the wrapped ability: `WrappedAbility.java:440` passes `sa`, not the wrapper). `announceTriggeredX` (`costparts.go`) asks `ChoosePayX` with the cost's mana; no new `PlayerController` method |
| Bounds | `XMax$` caps it (`AbilityUtils.getAnnouncementBounds`, `:3058-3060`; unresolvable is an error); a part of amount X caps it at what the part can pay (`nonManaXMax`, `PlayerControllerHuman.announceRequirements` `:376-381`). `XMin$` is refused (no corpus line among the refusals) |
| Read back | The value becomes the ability's `xManaCostPaid` and `Game.xctx` (refreshed after `Registry.resolve` captured it), so `Count$xPaid` reads it in the ability and every sub-ability |
| Computed X | Any other X (`Count$CardPower`, `Count$Valid Shrine.YouCtrl`, `Count$YourCountersExperience`, ...) is the card's own amount, read as the cost is paid (`CostPart.getAbilityAmount`); never asked |
| X 0 | `costWithX`: a part of amount 0 pays nothing, an X mana symbol is X generic mana. Myr Battlesphere with no Myr pays its cost for X 0 |
| Reflexive | An `ImmediateTrigger`'s copies carry the spawning ability's X, 0 when it announced none (`AbilityUtils.java:1649-1656`): Isareth's "pay {X}. When you do, ... mana value X" |
| Order | Shape checked first (an unread cost is an error before anyone is asked), then `ConfirmOptionalTrigger` (cost triggers are optional, `TriggerHandler.java:511-518`), then X, then the payment |

## Cost parts

New parts of `unlessCost`, so every payer reads them: a triggered `Cost$`, an `UnlessCost$`, a spell's own `Cost$`, an
optional cost. Paid by `payChoiceParts` (first, `paymentOrder` 5) and `payExtraParts` (`costparts.go`).

| Part | Java | Port |
| --- | --- | --- |
| `SubCounter<N/Type>` on the source | `CostRemoveCounter.java:151-199` (`payCostFromSource`) | Source not phased out with N counters of the kind (keyword counters included: Biting-Palm Ninja's Menace); removed through `removeCounters` |
| `RemoveAnyCounter<N/Kind/CARDNAME>` | `HumanCostDecision.java:1041-1060` | The source itself as the only permanent (`removeAnyCandidates`) |
| `Discard<N/Type>` | `CostDiscard` | N cards of the type from the hand (`ChooseCardsToDiscard`); `Discard<0/Hand>` (Vaultguard Trooper) is the whole hand, any amount |
| `ExiledMoveToGrave<N/Type>` | `CostExiledMoveToGrave.java:48-92` | N exiled cards of the type, any player's exile in seat order, to their owners' graveyards |
| `Forage` | `CostForage.java:19-70`, `HumanCostDecision.java:619-646` | Three graveyard cards exiled or a Food sacrificed; `ChooseOption` picks when both are possible; then `Mode$ Forage` fires (`TriggerForage`, `ValidPlayer$`) |
| `ExileFromHand<N/All>` | `CostExile.java:178-180` | The whole hand, always payable |
| `ExileCtrlOrGrave<N/Type>` | `Cost.java:487-492` | Permanents the payer controls, then graveyard cards, of the type |
| `RevealOrChoose<N/Type>` | `Cost.java:522-526` (`CostReveal` over Hand,Battlefield) | Behold's zones; `revealBehold` keeps Behold's own `canPay` apart |
| `ChooseCreatureType<1>` | `CostChooseCreatureType.java:51-58`, `HumanCostDecision.java:53-59` | Always payable; the payer names one of every creature type (`ChooseOption`), the host records it as its chosen type |
| `Behold<N/...ChosenType>` payability | `CostBehold.java:19-32` | Some hand or battlefield card shares a creature type with N of them, itself included (`beholdSharesType`) |

Every cost exile (`ExileFromGrave`, `ExileFromHand`, `Exile`, `ExileCtrlOrGrave`, Forage, CollectEvidence) marks the
card as exiled with the source (`exileCostCards`, `markExiledWith`; `CostExile.java:294`, `CostForage.java:52`,
`CostCollectEvidence.java:77`), and `ExileFromGrave` joins the cost's `Exiled` paid list.

A spell's own reveal (`Reveal`, `RevealOrChoose`, `Behold`, optional or not) has the payer pick the cards and records
them on the cast (`castOptional.revealed`) with each card frozen as it was paid (`castOptional.revealedLKI`,
`Card.frozenCopy`): Java's "Revealed" list holds LKI copies (`CostPartWithList.java:136-138`, `CostReveal`'s
`getHashForLKIList`), so `Revealed$CardPower` reads the power as paid. Another payer's reveal still asks nothing: it
changes no state this port reads.

## Engine state added

| State | Why | Clone |
| --- | --- | --- |
| `castOptional.revealedLKI []*Card` | Java's Revealed list is LKI copies; no existing record froze a card as a cost paid it | `castOptional.clone` copies each `frozenCopy` |
| `castOptional.exiled []CardID` | The optional costs' exiles, marked once the spell has its stack object | copied |
| `Ability.probing`, `Ability.probeTeamwork` | `canPlay(true)` asks a spell not yet cast about an optional cost it has not paid | value fields |
| `cost.ActivationShape.CollectEvidenceN` | Cryptex's activation cost | value field |

`Card.frozenCopy` is the snapshot copy `Game.Clone` already made for every LKI card, now shared.

## Pinned and reported

Dragon's Fire and Monstrous Emergence read the chosen or revealed card's power as the cost paid it (Java's LKI list,
`CostPartWithList.java:136-138`); reproduced (PORT-7). If the cards' rulings read a chosen creature's power as the spell
resolves, this is a Forge defect for `check-card` to confirm.
