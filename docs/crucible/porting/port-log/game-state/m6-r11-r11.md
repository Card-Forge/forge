# R11: attack costs (Propaganda, `Mode$ CantAttackUnless`)

Open-plan row R11. A `Mode$ CantAttackUnless` static (31 corpus lines: Propaganda, Ghostly Prison, Windborn Muse, Sphere
of Safety, Brainwash, Leviathan, Hollow Warrior, Nils, War Tax, ...) taxes a creature's attack (CR 508.1d, 508.1h-j).
Before this row the engine read none of them: every taxed attacker attacked for free. `attackcost.go` ports the tax,
`attack.go` pays it during the declaration and `attackconstraints.go` skips a costed pair when it searches for the best
legal attack.

## Port

| Piece | Port |
| --- | --- |
| Cost lookup | `attackCost(attacker, defender)`: every `CantAttackUnless` line on a trait host (battlefield, Command-zone effects, granted statics through `liveTraitFaces`) whose conditions hold and whose `ValidCard$`/`Target$` match; texts joined with a space (mana `2 2` parses as 4) |
| Params | `attackCostParams`; any other param, an unknown `Condition$`, a missing `Cost$`, an SVar `resolveNamedAmount` cannot read or a cost `parseUnlessCost` cannot hold (two `Sac` parts) is an `error`, never a free attack (GO-7) |
| Conditions | `staticConditionsMet` (zone, `Condition$`, `IsPresent$`); `knownStaticCondition` gains `Blessing`, `Monarch`, `EnduringStory`, which `continuousConditionMet` already evaluates (Dáin) |
| SVar cost | Evaluated on the static's host with its face amounts (Sphere of Safety, Collective Restraint, Myr Prototype, War Tax's chosen number on the effect card). Whipgrass Entangler's grant is still refused earlier (`Animate: staticAbilities$ not resolvable yet`) |
| Payment | A non-mana part `unlessPayable` rejects fails the cost unasked (`PlaySpellAbility.java:187-191`); else `ConfirmPayCost`, then `payUnlessCost` with an `Ability{Source: attacker}`: every `parseUnlessCost` part (mana, `WP`, `PayLife`, `Sac`, `Return`, `tapXType`). No new `PlayerController` method |
| Declaration | `DeclareCombatAttackers`: requirements checked against an `attackValidation` built before tapping, alone checks, every cost pre-read (an error changes nothing), combat committed, non-vigilance attackers tapped silently, `payAttackCosts`, then Taps triggers for the survivors, exert, attack triggers |
| Unpaid | `removeFromCombat`, untap if tapped here, `recheckAttackers` (requirements against the pre-tap constraints, alone restrictions). A failure untaps every provisionally tapped attacker, restores the previous combat and returns the `*IllegalDeclarationError`; what was paid stays paid |
| Absent | An attacker that left the battlefield while paying (a creature land sacrificed) leaves combat (`Combat.removeAbsentCombatants`) |
| Best attack | `legalAttack` skips a costed `(attacker, defender)` option and keeps the creature's other options; a "must attack" creature under Propaganda may stay home |

## Reproduced quirks (PORT-7)

| Quirk | Why kept |
| --- | --- |
| X-named SVar cost: Java appends an X shard and pays it as 0 (`CombatUtil.java:266`); the port drops the shard, same amount paid | No reader of "cost contains X" exists in the port |
| `RememberingAttacker$`: Java's `removeRemembered` also forgets an attacker the host remembered before; `Memory.Forget` does the same | Parity |
| Zero cost (Collective Restraint with no basic types) still asks `ConfirmPayCost` and still makes `legalAttack` skip the pair | Java's non-null `Cost` |

## Deviations

| Deviation | Reason |
| --- | --- |
| Exert is asked after the attack costs, of the attackers that paid; Java asks before and folds `Exert` into the same `Cost` (`PhaseHandler.java:564-578`) | Exert stays in `exertDeclaredAttackers`; outcome is the same, question order differs |
| Re-validation failure returns `*IllegalDeclarationError`; Java re-prompts the declaration in its `do ... while` | ADR-0024: the controller answers legally, the caller re-asks |
| Payment order is declaration order; Java walks `Combat.getAttackers()`, grouped by defender | Same order whenever every attacker attacks one defender |
| Requirement re-validation reuses the pre-tap constraints, costs read live; Java's `AttackConstraints` are equally stale but its restriction sets come from `initConstraints` | Rebuilding after the tapping would make every tapped attacker unable to attack |

## Not ported

| Gap | Why |
| --- | --- |
| CR 508.1i mana-ability window: `PayManaCost` pays from the pool only, and `beginStep` empties pools before `DeclareCombatAttackers`, so in a `Run`-driven turn no mana tax can be paid: a creature taxed by Propaganda, Ghostly Prison or Sphere of Safety always stays home (it attacked free before this row; Java's AI taps lands and pays, `ComputerUtil.playNoStack`) | Engine-wide: `UnlessCost$` at resolution has the same limit. Needs a mid-payment mana-ability decision for every payer; out of this row. Scenarios float mana by `tapformana` in the step first |
| `Mode$ CantBlockUnless` (10 lines: Hollow Warrior, Myr Prototype, Cowed by Wisdom, Whipgrass Entangler, ...): read as absent (`blockvalidation.go` header), so taxed blockers block free | Block costs, a separate row |
| `CardProperty` `couldAttackButNotAttacking` (`CombatUtil.java:95-119`, skips a costed pair at `:109`) | No reader in the port |
| `AttackRequirement.java:111` (`causesToAttack`) and `AttackConstraints.java:331` (`playerRequirements`) cost checks | Their modes (`Mode$ AttackRequirement`, `Mode$ PlayerMustAttack`) are still rejected |

## Forge defect

`PhaseHandler.java:577`: a re-validation failure after an unpaid attack cost re-prompts the declaration without
refunding what earlier attackers paid (Java's own TODO). The port keeps the payments too (PORT-8: reported, not
compensated).

## Tests

Module: `attackcosts_test.go` (Propaganda paid; Ghostly Prison declined drops one attacker; unpayable; Propaganda plus
Sphere of Safety summed; `Target$` vs a planeswalker; Brainwash `AttachedBy`; Leviathan `Sac<2/Island>`; Hollow Warrior
`tapXType` excludes a vigilance attacker (nobody asked) and taps a non-attacker; Dryad Arbor sacrificed for Exalted
Dragon's cost leaves combat, both declaration orders; Nils `RememberingAttacker$`; Archangel of Tithes and Dáin
conditions; must-attack creature may stay home; re-validation failure undoes combat and keeps the payment; five error
shapes). Scenarios: `attack-cost-propaganda-tax-paid-attacker-deals-damage`,
`attack-cost-ghostly-prison-declined-attacker-stays-home`, `attack-cost-exalted-dragon-sacrifices-a-land-to-attack`.

## Measurement

`card-smoke -all -workers 8 -list`, before and after: identical, line for line.

| Run | Plays | Refused | Placed | Inconclusive | Judged | Play rate |
| --- | --- | --- | --- | --- | --- | --- |
| Before | 30,906 | 2,712 | 379 | 81 | 33,618 | 91.9% |
| After | 30,906 | 2,712 | 379 | 81 | 33,618 | 91.9% |

No card moved: every one of the 31 lines' shapes resolves, so no taxed card became a refusal, and none was refused
before (the static was ignored, not rejected). The gain is correctness the probe does not see: a taxed attacker now pays
or stays home.
