# What is Reforge Commander?

Reforge Commander is a **Commander-first fork of [Forge](https://github.com/Card-Forge/forge)**, a
"Rules Engine" for the game Magic: The Gathering. It exists so I can play Commander with friends with a
cleaner, faster client — nothing more.

- Not related in any way with Wizards of the Coast.
- Inherits Forge's open-source engine, released under the GNU Public License.
- Supports up to 8 players, each assigned to human or AI control. Decks can be imported, user-created
  with the Deck Editor, or automatically generated.
- Over 99% of all cards in Magic's existence are available (see [Missing Cards](Missing-Cards-in-Forge.md)),
  with the missing ones mostly being pointless to implement in context or impossible.
- Non-Commander modes from upstream Forge (Quest mode, Planar Conquest, Adventure, puzzles, etc.) are
  **hidden by default** in this fork.

For the full original documentation, mechanics, and feature list, see the
[Forge Wiki](https://github.com/Card-Forge/forge/wiki) — this repository mirrors the docs but the
upstream wiki remains the authoritative source for card scripting and game mechanics.
